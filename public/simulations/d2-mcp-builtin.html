How this simulation works

  1. Choose where the MCP server is configured and how its token is stored.
  2. Decide whether to expose data as MCP resources, then pick a built-in tool for the search task.
  3. Press Run. Each choice moves the four metrics deterministically; the generated .mcp.json reddens if you inline a secret.
  4. Goal: 100% setup correctness, zero secret-leak risk, an efficient search, and few exploratory calls.
