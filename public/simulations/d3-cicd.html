Standing Up a Nightly Review Bot in CI

You are wiring Claude Code into a nightly CI job that reviews the day's merges. Six configuration choices decide whether the job runs clean, parseable, and safely scoped — or hangs the pipeline, breaks your parser, pollutes every teammate's context, rubber-stamps its own code, hands automation the whole machine, or silently swallows the exit code so the build never fails.
