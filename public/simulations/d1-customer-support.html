How this simulation works

  1. Pick an incoming ticket and set the agent's guardrails.
  2. Press Submit ticket. The log narrates the agentic loop; metrics update.
  3. Each guardrail is a deterministic config→consequence. Turn one off and watch a metric degrade — mis-identification turns Alps red the instant it rises above zero.
  4. Goal: a configuration that holds first-contact resolution at 80%+ with a zero mis-identification rate.
